# 律师工作台（Lawyer Workbench）

面向中国法律工作流的单文件离线小工具，使用 [AutoClaw](https://autoclaw.zhipuai.cn/) 构建。

## 功能（八大模块）

| 模块 | 说明 |
|---|---|
| 案件看板 | 一案件一档案：当事人、我方立场、状态、四类工作计数 |
| 时间线整理 | 事件按日期排序，区分「已确认 / 待核实」，导出 Word / Markdown / CSV |
| 证据目录 | 编号、来源、证明目的、三性备注、证据缺口与补证建议 |
| 合同审查 | 8 类合同审查要点清单 + 条款风险标注（必须修改/建议谈判/可接受），导出审查意见表 |
| 文书生成 | 律师函、催款函、法律备忘录、民事起诉状模板，实时预览，导出 Word |
| 文件脱敏 | 正则识别手机号/身份证/邮箱/银行卡/金额 + 自定义敏感词，产出脱敏文件 + 回填映射表（可逆向还原） |
| 依据线索 | 法条快查（国家法律法规数据库 / 北大法宝 / 裁判文书网 / 人民法院案例库），依据存档导出 |
| 设置 | 数据 JSON 备份导入导出；可选接入智谱 API 做 AI 条款分析 |

## 使用

- **index.html**：正式工具，双击即用。数据保存在浏览器 localStorage，仅存本机，不上传任何服务器。
- **demo.html**：内置一套**虚构演示案件**（星辰科技诉云帆贸易买卖合同纠纷，人名/号码/案号均为假数据），打开即是填好的界面，便于快速了解各模块形态。

## 声明

- 本工具输出均为工作初稿，不构成法律意见；正式对外文件请由执业律师复核签发。
- 引用法条/案例前请在官方数据库核对现行有效版本。
